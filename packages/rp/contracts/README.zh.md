# @dsh-rp/contracts

[English](README.md) | 中文

供 Host 插件、Web 客户端、包工具和兼容适配器共享的客户端安全 RP 数据声明。每个持久化或外部表示都带有 `schemaVersion`；运行时无法理解的导入字段在 `CompatibilityEnvelope` 中保持非活动状态。

不透明标识符使用品牌字符串。本包不拥有存储、注册、执行或默认值行为。

## 模型体验

无。本包只提供类型，不装配提示词、schema、消息或模型请求。

#### KV Cache 影响

无；本包没有运行时模型上下文贡献。

## 已知限制与延期工作

- **仅支持 schema 版本 1**——迁移由导入或持久化插件负责，因为本包不包含运行时解析器。
