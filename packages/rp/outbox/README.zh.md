# @dsh-rp/outbox

[English](README.md) | 中文

为不能纳入 RP 单轮本地原子提交的副作用提供幂等 Outbox 与补偿式 Saga 运行时。Handler 是可逆插件；条目具有有界重试、稳定幂等键、确定性检查和显式终态。

Saga 步骤顺序执行，失败后按逆序补偿已成功的步骤。运行时绝不会把网络、媒体或文件系统工作描述成数据库事务。

## 模型体验

无，因为该服务执行已经提交的外部副作用意图，不向模型请求贡献内容。

#### KV Cache 影响

无。

## 已知限制与延期工作

- 持久化存储与分布式租约由 Provider 负责；内置实现是进程内参考运行时。
