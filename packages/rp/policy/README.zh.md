# @dsh-rp/policy

[English](README.md) | 中文

把可逆的部署/产品层与单次调用的插件、用户、agent 和预算层取交集，计算插件及 agent 的有效权限。返回决策中的权限、域名 allowlist、文件根目录、信任上限和数值预算均不可变。

任一层把操作限制到 L0 或 L1 时，L2 请求会被拒绝而不是静默降级。显式空 allowlist 会拒绝该维度的全部请求；省略 allowlist 则不限制该维度。

该服务会把自己注册为可逆的 Capability Catalog authorizer。因此，每次统一能力调用都会先合并部署层、产品层、插件描述符、用户或 agent 上限与单次调用层，再把控制权交给原始适配器。

## 模型体验

无，因为策略服务只过滤权限，不贡献提示词或提供方请求内容。

#### KV Cache 影响

无。

## 已知限制与延期工作

- 规范化域名和文件系统路径属于具体的网络/文件系统沙箱提供方；本服务只对声明名称取交集。
- 发布者的密码学信任独立于运行时信任级别。
