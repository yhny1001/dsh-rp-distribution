# `@dsh-rp/compat-stscript`

[English](README.md) | 中文

这是一个需要显式权限的 L1 兼容插件，实现 SillyTavern STscript 与 Quick Reply 中安全、确定性的语义子集。它支持管道值、局部/全局变量、有界算术、`{{pipe}}` 与变量宏、输出，以及调用显式传入的 Quick Reply 库。

解释器是纯函数式边界并采用 fail-closed 策略。它不能访问模型、消息、网络、文件系统、Shell、任意 JavaScript、扩展或 Host。执行边界会限制源大小、命令数、调用深度、变量数、序列化状态、输出、取消信号与 Capability 预算。仅安装插件不会授予执行权；调用者必须拥有 `script.execute`。

## 模型体验

无，因为解释器只返回已脱离运行时的 JSON，不会装配模型输入。

#### KV Cache 影响

在其他插件主动把执行结果渲染到模型上下文前没有影响。

## 已知限制与延期工作

- 本插件有意不做完整 SillyTavern 模拟。生成、聊天修改、延时、循环、闭包、UI 命令、HTTP、文件、扩展与任意代码都会被拒绝。
- Quick Reply 库必须在每次调用时显式提供；本插件不会扫描用户目录或应用目录。
- 后续命令必须作为独立审查过的语义适配器加入，不能扩大解释器的环境权限。
