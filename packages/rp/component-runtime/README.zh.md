# @dsh-rp/component-runtime

[English](README.md) | 中文

`ctx.rpComponents` 是 RP 包贡献的动态注册表。每次注册都会返回 disposer；解析过程会校验精确依赖、支持的 scope 和已授予能力，然后发布不可变的 `RpCompositionSnapshot`。

组合 id 对 scope、权限、组件版本、依赖和声明能力进行哈希。`createdAt` 仅用于观察，不参与哈希，因此等价解析拥有相同身份，同时保留各自发布时间。

版本要求目前接受精确版本或 `*`。缺失的可选依赖会跳过；缺失的必需依赖、循环、scope 不匹配及被拒绝的必需能力会使解析失败。

## 模型体验

通过使用冻结组合来装配提示词、工具、agent 和流水线的消费者间接产生影响。

#### KV Cache 影响

无直接影响。消费者可用确定性组合 id 保留或失效自己装配的前缀。

## 已知限制与延期工作

- **精确版本匹配**——在包注册表拥有唯一规范的 semver 解析器前，暂不进行范围协商。
