# `@dsh-rp/registry-artifacts-local`

[English](README.md) | 中文

这是 `ctx.rpRegistry` 的持久化内容寻址归档缓存。默认根目录为 `$DSH_HOME/rp/package-artifacts`；部署可以配置其他私有根目录和归档大小上限。

每次写入都必须匹配其小写 SHA-256 键。发布过程在进程之间串行化，先写入仅所有者可访问的临时文件，刷新后再重命名到两级摘要路径。读取会拒绝符号链接、非普通文件、超大内容和摘要不匹配。Registry 在写入缓存前验证来源证据，并向生命周期适配器提供独立副本。

缓存会跨插件卸载和 Host 重启保留归档。卸载只会移除 Registry Provider，不会删除用户包数据。

## 模型体验

通过 Agent 或 Pipeline 选择的已恢复插件能力间接产生影响。

#### KV Cache 影响

自身不产生影响。只有通过验证激活并显式选择能力后，缓存归档才会影响上下文。

## 已知限制与延期工作

- 文件和父目录的 fsync 可移植性取决于后端；归档文件会在重命名前刷新，但突然断电后仍可能需要重新获取。
- 缓存淘汰、跨归档总配额、远程缓存复制和遗留写锁的运维修复由独立策略插件负责。
