# @dsh-rp/character

[English](README.md) | 中文

`ctx.rpCharacters` 在精确生命周期作用域中保存与调用方分离的 `CharacterIR` 资产。`context()` 提供有界、确定性的模型视图，并排除兼容信封、扩展字段和问候语候选。

## 模型体验

由第一方或第三方 Prompt 消费者显式选择安全角色上下文视图，从而间接影响模型体验。

#### KV Cache 影响

角色上下文在冻结的单轮快照内保持稳定；按标识符确定性排序，避免注册顺序造成缓存抖动。

## 已知限制与延期工作

- 当前仅执行精确作用域选择；从角色库激活到会话的策略由 Experience 或 UI 插件负责。
- 角色问候语仍属于 UI 或分支输入，不会自动进入系统上下文。
